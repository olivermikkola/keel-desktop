# Keel Desktop v0.7.1

## What's new in Keel Desktop v0.7.1

### Signed 1-click in-app auto-updates (#61)
- **Update without leaving the app:** Keel Desktop checks for new signed releases in the background on launch (and on demand via **Settings → App updates → Check for updates**).
- **1-click Update & restart:** When a new version is available, a subtle banner appears in the sidebar with **Update & restart** — Keel stops the local model engine cleanly, downloads and verifies the Ed25519 signature, installs in place (macOS, Windows, and Linux AppImage), and relaunches automatically.
- **Package-managed Linux fallback:** `.deb` and `.rpm` installs still detect new versions and offer a 1-click **Download update** link to the release page.
- **Signed release manifests:** Release workflows now publish `latest.json` and `.sig` files automatically so every release after `v0.7.1` updates right inside the app.

### Also included from v0.7.0 (#57, #58, #60)
- **Models → Discover**, native `.gguf` drag-and-drop, one-click **Scan ~/Models**, repo URL downloads, and **Bonsai 2.5 · 27B**.
- **Live context-window meter**, tidy automatic titles, empty-chat reuse, one-click **Continue** on interrupted replies, 4K context cap option, BOM CSV stripping, and cleaner `</think>` handling.

### Installers
- **macOS:** `.dmg` (Apple Silicon `aarch64` & Intel `x86_64`) + signed `.app.tar.gz` updater bundle
- **Linux:** `.AppImage` (with signed in-app updater), `.deb`, and `.rpm`
- **Windows:** `.exe` (NSIS) & `.msi` (with signed in-app updater)
