# Draft release notes (paste when tagging)

## What's new in Keel Desktop v0.6.0

### One coding engine
- **Keel CLI for Code:** When `keel` is on PATH, Code prefers the CLI (streaming events, approvals, shared JSONL). New installs default to it; existing Settings choices stay put.
- **Import CLI sessions** from `~/.keel/sessions`; Show journal / Export journal handoff.
- **Windows:** CLI detection (`.exe`/`.cmd`/`.bat`) and CREATE_NO_WINDOW spawn; honest notice that Windows has no landlock/Seatbelt confinement.

### Smarter local scheduling
- **VRAM inventory:** Free graphics memory informs model fit and placement; insufficient free VRAM falls back to the processor with a clear reason.
- **Pack manifests:** Shared skeleton for capability packs with place/unload helpers; `prepare_pack_vram` stops keep-alive when packs need graphics memory.
- **Checksummed pack install:** Settings can download and remove capability packs (demo fixture + audio stubs); SHA-256 verified into the local data directory.

### Reliability evidence
- **Eval packs:** `smoke` everyday cases plus a larger `held_out` suite via `evaluate_local` (`KEEL_EVAL_PACK`, `KEEL_EVAL_RUNS`, TTFT via first content delta).
- **Published targets:** Formal table for TTFT / answer latency / success / peak RSS — fill with measured numbers via `scripts/publish_eval_targets.py`; GPU/Metal not inferred from CPU.

### Hub: remote text + audio packs
- **Explicit remote providers:** Non-loopback servers require confirmation; optional API keys stored with restricted permissions (never in `config.json`); location/cost copy in Models and Welcome. No silent cloud fallback.
- **Audio packs:** STT/TTS catalog in Settings with mark-installed, local or Whisper.cpp runner registration, and download-URL stubs. Whisper lists an unpinned `keel-pack:unpinned/…` placeholder (refused until a checksummed artifact is pinned). `run_audio_stt` dispatches `local` / `whisper_cpp` adapters from `runner.json` after `prepare_pack_vram`. Missing runner, missing ggml weights, or pack fails clearly. Checksummed Whisper downloads and TTS adapters still ahead.

### Installers
- **macOS:** `.dmg` (Apple Silicon `aarch64` or Intel `x86_64`)
- **Linux:** `.deb`, `.rpm`, or `.AppImage`
- **Windows:** `.exe` (NSIS) or `.msi`
