# Draft release notes (paste when tagging)

## What's new in Keel Desktop v0.6.0

### One coding engine
- **Keel CLI for Code:** When `keel` is on PATH, Code prefers the CLI (streaming events, approvals, shared JSONL). New installs default to it; existing Settings choices stay put.
- **Import CLI sessions** from `~/.keel/sessions`; Show journal / Export journal handoff.
- **Windows:** CLI detection (`.exe`/`.cmd`/`.bat`) and CREATE_NO_WINDOW spawn; honest notice that Windows has no landlock/Seatbelt confinement.
- **Fake-CLI e2e** covers stream, approvals, reasoning/sentinel, and Windows handshake; Diff/`--shadow` waits on a real file-edit protocol event.

### Smarter local scheduling
- **VRAM inventory:** Free graphics memory informs model fit and placement; insufficient free VRAM falls back to the processor with a clear reason.
- **Pack manifests:** Capability packs with place/unload helpers; `prepare_pack_vram` stops keep-alive when packs need graphics memory.
- **Checksummed download / remove** for pack assets in the Models UI.

### Reliability evidence
- **Eval packs:** `smoke` everyday cases plus a larger `held_out` suite via `evaluate_local` (`KEEL_EVAL_PACK`, `KEEL_EVAL_RUNS`).
- **TTFT instrumentation** from first content delta; fill published targets with `scripts/publish_eval_targets.py` after hardware runs (no invented numbers).
- **GPU/Metal:** Measure separately; do not infer from CPU.

### Hub: remote text + audio
- **Explicit remote providers:** Non-loopback servers require confirmation; optional API keys stored with restricted permissions (never in `config.json`); location/cost copy in Models and Welcome. No silent cloud fallback.
- **Audio packs:** STT/TTS catalog with checksummed download (demo fixture + Whisper tiny q5_1 from Hugging Face). Whisper base stays unpinned. `run_audio_stt` / `run_audio_tts` dispatch adapters after `prepare_pack_vram`. Additional TTS engines and artifacts UI still ahead.

### Installers
- **macOS:** `.dmg` (Apple Silicon `aarch64` or Intel `x86_64`)
- **Linux:** `.deb`, `.rpm`, or `.AppImage`
- **Windows:** `.exe` (NSIS) or `.msi`
