# Keel Desktop v0.7.2

## What's new in Keel Desktop v0.7.2

### Longer context & faster, smarter local tool calling (#64)
- **Real GGUF context windows (32K / 64K / 128K):** Keel now reads `*.context_length` directly from local and imported `.gguf` headers instead of capping imported models at 16K, raises automatic context to 32K on 48 GB+ machines, adds 64K and 128K options in **Settings → Developer options → Context window**, and automatically enables Q8_0 KV-cache quantization (`-ctk q8_0 -ctv q8_0`) for 32K+ sessions.
- **KV-cache-preserving compaction & in-turn reasoning:** Preserves `reasoning_content` across tool calls within a turn so thinking models keep their plan and achieve 100% KV prefix reuse across consecutive tool steps, while compacting oldest tool outputs first into immutable stubs instead of truncating the file the model just read.
- **Tighter workspace tools:** `list_files` now walks breadth-first in sorted order and skips noisy cache/build folders (`cache`, `__pycache__`, `build`, `.keel`, `vendor`, etc.); `search_files` supports an optional `path` filter; `read_file` streams lines so paging past 64 KB works reliably and caps default unread reads to 250 lines / 16 KB with total line counts.
- **No empty step-limit aborts:** Raises the agent step limit to 20, supports up to 4,096 output tokens per step, and runs a final KV-preserving synthesis pass (`tool_choice: "none"`) if the step limit is reached.
- **Accurate context meter & thinking-off support:** Context meter now displays latest-step context occupancy instead of cumulative multi-step prompt totals, and disabling thinking also sends `reasoning_effort: "none"`.

### Embedded offline Arena compare viewer (#63)
- **Arena sidebar panel:** Pick any local [Keel Arena](https://github.com/olivermikkola/keel-arena) results JSON and browse Compare, Dashboard, and Overview tabs offline inside Keel Desktop, with confined bundle reads, automatic temp-dir cleanup, and cross-platform Python lookup.

### Startup workspace & newer local engine discovery (#65)
- **Open folders from CLI or file manager:** Launch `keel-desktop /path/to/repo` (or `--workspace` / `--root`) to open straight into that folder; the folder picker now starts in your current folder or `~/Projects`.
- **Newer local `llama-server` auto-selection:** Propagates `LD_LIBRARY_PATH` on Linux for sidecar GPU libraries, prefers a newer local `llama-server` build over the pinned build when installed (enabling newer GGUF architectures), and surfaces a clear message on `unknown model architecture`.

### Installers
- **macOS:** `.dmg` (Apple Silicon `aarch64` & Intel `x86_64`) + signed `.app.tar.gz` updater bundle
- **Linux:** `.AppImage` (with signed in-app updater), `.deb`, and `.rpm`
- **Windows:** `.exe` (NSIS) & `.msi` (with signed in-app updater)
