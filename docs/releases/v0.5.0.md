## What's new in Keel Desktop v0.5.0

### Web search & Chat vision
- **Approved web search:** Chat, Work, and Code can call `web_search` after the same approval path as shell/MCP (`Allow once` / `Allow for this chat` / `Deny`). Results leave the machine over the public web; answers still come from your local or connected model. There is no silent cloud chat fallback.
- **Vision in Chat:** Image attachments keep their pixels and Chat sends OpenAI-compatible multimodal `image_url` parts. OCR remains an optional caption/fallback when Tesseract is installed or when a text-only model rejects images. Import still works without Tesseract when pixels are present.

### Keep the model ready
- **Hardware-aware setup:** Guided setup notices RAM and the graphics chip before recommending a model.
- **Graphics or processor:** Settings can choose Automatic, Graphics chip, or Processor. That choice reaches the runner.
- **Keep-alive:** A later message reuses the same process when the model, context, and that choice are unchanged, instead of loading the model again.
- **Check this model:** Settings runs three short questions (a saved preference, a number in a note, and a question the note does not answer). A model that fails is not offered as the one for this computer; it stays installed and can still be started by hand.
- **Answer timing:** The status line shows how long the last answer took.

### Installers
- **macOS:** `.dmg` (Apple Silicon `aarch64` or Intel `x86_64`)
- **Linux:** `.deb` (Ubuntu/Debian), `.rpm` (Fedora/RHEL), or `.AppImage`
- **Windows:** `.exe` (NSIS) or `.msi`
