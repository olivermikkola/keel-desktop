# Keel Desktop v0.7.0

## What's new in Keel Desktop v0.7.0

### Effortless model discovery & local GGUF bring-your-own (#57)
- **Discover tab in Models:** Browse trending or searched GGUF repositories from Hugging Face Hub, automatically pick the best standalone quantization (skipping `mmproj`, shards, and `imatrix`), filter to models that fit your computer's RAM/VRAM, and download in one click.
- **Native `.gguf` drag-and-drop & `Scan ~/Models`:** Drop `.gguf` model files anywhere onto the Keel window to import them directly (non-GGUF drops continue to attach documents), or click **Scan ~/Models** to import validated local models automatically.
- **Repo URL / `owner/repo` downloads:** Paste any Hugging Face repo URL or `owner/repo` string (such as `prism-ml/Ternary-Bonsai-2.5-27B-GGUF`) instead of hunting for raw `/resolve/main/...` links.
- **Bonsai 2.5 · 27B** added to the default model catalog.
- **Cold-load resilience & log details:** Local runner startup wait extended from 45s to 120s for larger GGUF files, with collapsible **Engine log details** in the Models inspector when a model fails to start.

### UI/UX & Keel Mobile parity polish (#58)
- **Live context window meter pill:** Shows live conversation memory usage (`2.4K / 16K (15%)`) in the status bar and highlights at `>= 75%` when automatic compaction is approaching.
- **Tidy automatic conversation titles:** Strips polite openers (`"Can you please..."`, `"Hey..."`), collapses accidentally doubled words, cuts cleanly at word boundaries, and capitalizes the title.
- **No duplicate empty chats:** Clicking **New chat** or switching modes reuses an existing untouched empty thread with the same preset, folder, and project.
- **One-click `Continue` on interrupted replies:** Resume partial or stopped replies with one click instead of retyping.
- **Smoother model switching & context controls:** Auto-starts newly downloaded Hugging Face / Discover models when no model is running, adds a **Discover or add .gguf…** shortcut and active context size label to the topbar model switcher, and adds a `4,096` token context cap option in Settings for lighter memory use.
- **Small-model harness fixes:** Strips UTF-8 BOM from Excel/Numbers-exported CSVs before mounting SQLite tables, and handles template-prefixed `</think>` blocks cleanly.

### Keel Code (CLI) naming & measured eval targets (#54, #55, #56)
- Labeled the external CLI engine consistently as **Keel Code (CLI)** and updated docs/links to `olivermikkola/keel-code`.
- Published measured Linux CPU and Vulkan GPU held-out evaluation targets.

### Installers
- **macOS:** `.dmg` (Apple Silicon `aarch64` & Intel `x86_64`)
- **Linux:** `.deb`, `.rpm`, `.AppImage`
- **Windows:** `.exe` (NSIS) & `.msi`
